Petunjuk merekam video (MP4)

Proyek ini hanya memutar animasi di browser, tidak membuat file video secara otomatis. Berikut dua cara mudah merekam hasilnya menjadi MP4:

Cara 1 — Screen recorder (paling mudah)

  1. Buka index.html di browser, perbesar jendela browser (atau mode fullscreen / F11).
  2. Gunakan aplikasi perekam layar: Windows → Win + G (Xbox Game Bar) atau Win + Shift + S variasi, bisa juga pakai OBS Studio (gratis, hasil lebih rapi).
  3. Klik tombol Putar Ulang lalu mulai rekam dari frame pertama hingga animasi selesai (±53 detik).
  4. Simpan hasil rekaman sebagai .mp4 (OBS: atur "Recording Format" ke mp4 di Settings → Output).

Cara 2 — Ekspor frame otomatis dengan ffmpeg (lebih presisi)

  1. Install ffmpeg di komputer.
  2. Buka console browser (F12) saat index.html terbuka, lalu jalankan skrip kecil untuk menangkap setiap frame canvas sebagai PNG berurutan ke folder unduhan (skrip capture manual, lihat komentar di script.js bagian // EXPORT FRAME (opsional)).
  3. Gabungkan seluruh frame PNG menjadi video dengan perintah:
    ffmpeg -framerate 30 -i frame_%04d.png -c:v libx264 -pix_fmt yuv420p ecosense_video.mp4

Cara 1 sudah cukup untuk kebutuhan presentasi singkat.
